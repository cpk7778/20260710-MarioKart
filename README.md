# 미니 카트 레이스 (React + Vite + Three.js 프로토타입)

3D 원형 트랙을 도는 초간단 카트 레이싱 프로토타입입니다.

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 뜨는 주소(기본 http://localhost:5173)를 브라우저에서 열면 됩니다.

## 조작법

- `↑` / `W` : 가속
- `↓` / `S` : 브레이크 · 후진
- `←` `→` / `A` `D` : 조향 (속도가 있어야 회전 반경이 나옵니다)

## 구조

```
src/
  App.jsx              # HUD(속도계, 조작법) + Scene 조합
  App.css              # HUD 스타일
  components/
    Scene.jsx           # Canvas, 조명, 카메라 추적(3인칭 시점)
    Track.jsx           # 원형 도로, 잔디, 안팎 벽, 출발선
    Kart.jsx             # 카트 3D 모델 + 주행 물리(가속/브레이크/조향/트랙 이탈 방지)
  hooks/
    useKeyboard.js       # 방향키/WASD 입력 상태 추적
```
